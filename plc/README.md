# Программа ПЛК: резервирование ЧРП (24 контактора)

Файл `VFD_Redundancy.st` — логика управления на языке Structured Text (IEC 61131-3).
Подходит для CODESYS 3.5 и ABB Automation Builder (ПЛК AC500).

## Что внутри

| Блок | Что делает |
|---|---|
| `F_PermitClose` | Проверяет блокировки Б1–Б5 перед замыканием любого контактора, возвращает код причины отказа |
| `F_PermitOpen` | Б3: контактор ЧРП размыкается только при заблокированном выходе |
| `FB_TransferToMains` | Перевод двигателя с ЧРП на сеть на ходу: 50 Гц и синхронизм → блокировка выхода → размыкание 1A1 → подтверждение → замыкание BA1 в окне 250 мс |
| `FB_ConnectToDrive` | Подключение двигателя к ЧРП: блокировка выхода → замыкание 1B1 → подтверждение → разрешение работы с подхватом на ходу |
| `PRG_Main` | Основной цикл (10 мс): контроль приваривания, проверка инвариантов, реакция на аварию ЧРП (Б5), подхват двигателя исправным ЧРП, запросы оператора |

## Блокировки

| Код | Правило |
|---|---|
| Б1 | У двигателя замкнут только один из трёх контакторов (1A1, 2A1, BA1) |
| Б2 | У ЧРП замкнут только один из восьми контакторов |
| Б3 | Контакторы ЧРП переключаются только при заблокированном выходе; работа разрешается после подтверждения положения |
| Б4 | На сеть — только при 50 Гц и синхронизме, в окне 250 мс после блокировки выхода; стоящий двигатель можно пускать от сети напрямую |
| Б5 | Отказавший ЧРП: выход заблокирован, все его контакторы и вводной автомат Q отключены |
| 6 | Команда и обратная связь контактора расходятся дольше 500 мс (приваривание или обрыв) → двигатель блокируется |

Б1 и Б2 дублируются аппаратно в цепях катушек контакторов (НЗ вспомогательные контакты, зеркальные контакты по IEC 60947-4-1, прил. F) и работают даже при отказе ПЛК.

## Сигналы

**Входы:** вспомогательные контакты всех 24 контакторов и Q1, Q2; защита FA/FB; реле нулевой скорости двигателей; от ЧРП по Profinet/Modbus TCP: авария, выход заблокирован, синхронизм, частота.

**Выходы:** катушки 24 контакторов; независимые расцепители Q1, Q2; разрешение работы, подхват на ходу, задание частоты и запрос синхронизации для каждого ЧРП.

## Как открыть в CODESYS

1. Создайте Standard project с любым ПЛК (для проверки подойдёт CODESYS Control Win V3).
2. Создайте объекты: DUT для каждого `TYPE`, GVL для двух блоков `VAR_GLOBAL`, POU для функций, функциональных блоков и `PRG_Main`.
3. Скопируйте в каждый объект соответствующий фрагмент файла.
4. Добавьте `PRG_Main` в задачу с циклом 10 мс, скомпилируйте (F11) и запустите в режиме симуляции.

Код не проходил компиляцию в CODESYS: проверены только логика и структура. При первой сборке возможны мелкие синтаксические правки.
