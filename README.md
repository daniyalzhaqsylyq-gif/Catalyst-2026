# Catalyst 2026 · кейс ABB: резервирование ЧРП

Интерактивная мнемосхема (экран оператора, HMI) для схемы байпаса и перекрёстного резервирования
двух ЧРП и восьми двигателей на 24 контакторах.

**Открыть онлайн:** https://daniyalzhaqsylyq-gif.github.io/Catalyst-2026/

## Что показывает
- 7 сценариев: каскадный пуск групп A и B, перевод двигателя на сеть на ходу, отказ ЧРП 1, отказ ЧРП 2, отказ обоих ЧРП, сброс.
- Ручное управление: клик по контактору или вводному автомату.
- Блокировки Б1–Б5 реально запрещают опасные команды:
  - Б1 — у двигателя замкнут только один из трёх контакторов;
  - Б2 — у ЧРП замкнут только один из восьми контакторов;
  - Б3 — контакторы ЧРП переключаются только при заблокированном выходе;
  - Б4 — перевод на сеть только при 50 Гц и синхронизме;
  - Б5 — у ЧРП в аварии отключены Q и все его контакторы.
- Журнал событий и пошаговое выполнение последовательностей.

## Программа ПЛК

Папка [`plc/`](plc/) — та же логика в виде программы для ПЛК на языке IEC 61131-3 Structured Text
(CODESYS 3.5 / ABB Automation Builder, AC500): проверка блокировок Б1–Б5, перевод двигателя на сеть,
подключение к ЧРП с подхватом на ходу, реакция на аварию ЧРП, контроль приваривания контакторов.
Описание блоков и сигналов — в [`plc/README.md`](plc/README.md).

Один файл `index.html`, без зависимостей, работает офлайн.
